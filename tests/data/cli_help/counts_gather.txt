                                                                                                    
 Usage: root counts gather [OPTIONS] REGIONS                                                        
                                                                                                    
 Gather ``counts bam``'s per-track cache into one ``RegionCountData`` run.                          
                                                                                                    
 Writes to ``--dataset-dir``.                                                                       
                                                                                                    
╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    regions      PATH  Same region set passed to 'counts bam' [required]                        │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ *  --tracks                PATH     Same tracks.parquet passed to 'counts bam' [required]        │
│ *  --out-dir       -o      PATH     Per-track parquet cache written by 'counts bam' [required]   │
│ *  --dataset-dir           PATH     Output RegionCountData run directory [required]              │
│    --chrom-sizes           PATH     chrom.sizes/.fai for the region bounds check                 │
│    --target-width          INTEGER  Width of the counted window, centred on each region          │
│                                     [default: 1000]                                              │
│    --val-chroms            TEXT     Chromosomes assigned split=val with no 'split' column        │
│    --test-chroms           TEXT     Chromosomes assigned split=test with no 'split' col          │
│    --help                           Show this message and exit.                                  │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
